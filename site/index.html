Control your Eveus EV charger from Home Assistant.

A Home Assistant integration for Eveus EV chargers of all three hardware generations, on Eveus or REVE firmware. It lets you control the charging state, current, schedules, limits, the charger's time settings and many other parameters. It also calculates your car's battery level (SOC) while charging and can end the charge at the level you choose. A ready-made dashboard card shows all of this together with energy, charging cost and safety readings: voltage, temperature, grounding and leakage current.

Built for useful EV charging automations

Charging control

The integration controls the charging state, current, schedules, limits, adaptive mode, ground protection and the charger's clock (time zone and time sync). It also lets you manage the charger's optional OCPP connection.

All hardware generations

The integration recognizes Eveus firmware 1.x, 2.x and R3.x and the REVE firmware by itself and sends each command the way that firmware expects. It is built for the latest version of each firmware line.

Events and device triggers

The integration fires events on real charger transitions — charging started or finished, car connected or disconnected, error — and offers them as ready-made device triggers in the automation editor. The finished event carries the session's energy, cost, and duration. State and Substate are enum sensors, so state triggers offer a dropdown of valid values.

Energy and cost

The integration exposes the charger's current voltage, current, and power measurements, along with session energy, total energy, resettable counters, tariffs, and charging costs. Last Session sensors keep each finished session's energy, cost, and duration until the next session completes — and past sessions stay in their history.

SOC and stop at a target

In Advanced mode, the integration calculates your car's battery level (SOC), time to target, finish time, remaining grid energy and expected cost from charger data and your battery details, and can end the charge at the level you choose.

Ready-made dashboard card

One card shows the charger's state and controls together with energy, charging cost and safety readings: voltage, temperature, grounding and leakage current. You pick and reorder its sections in the card editor.

Safety notices

The integration creates Home Assistant Repairs issues for confirmed missing ground, disabled ground protection, overheating, excessive leakage current, charger faults, and a low internal backup battery.

Real-network resilience

The integration adapts its polling rate, handles powered-off chargers without repeated log noise, confirms commands against charger responses, starts reauthentication when credentials fail, and redacts exported diagnostics.

English and Ukrainian

The integration includes English and Ukrainian Home Assistant translations. You can also add multiple Eveus chargers; Home Assistant creates a separate device and entities for each one.

Install the integration through HACS

  1. Open HACS (from Home Assistant 2026.11, Settings → Marketplace) and search for Eveus EV Charger — it is in the HACS default store, so no custom repository is needed.
  2. Install it and restart Home Assistant.
  3. Open Settings → Devices & Services → Add Integration, then search for Eveus EV Charger.
  4. Enter the charger address and, if the charger has them, the username and password of its web interface; then choose the charger model, phase count, and integration mode.

Requirements: an Eveus 16A, 32A, 40A or 48A charger on the latest firmware of its line (Eveus 1.x, 2.x or R3.x, or REVE), reachable from Home Assistant on your network.

Frequently asked questions

Does the Eveus EV charger work with Home Assistant?

Yes. The Eveus EV Charger integration connects Home Assistant to Eveus 16A, 32A, 40A and 48A chargers of all three hardware generations, on Eveus or REVE firmware, and is installable through HACS.

Which Eveus chargers and firmware are supported?

All three hardware generations. Each has its own Eveus firmware line: 1.x, 2.x and R3.x; the third generation can also run REVE. The integration recognizes the firmware by itself. It is built for the latest version of each line; on older versions it may work only partly.

Does the integration need a cloud account?

No. The integration communicates with the charger only over your local network — no cloud account and no telemetry. The charger's own optional OCPP connection is a separate feature and may use a remote backend.

Can Home Assistant estimate the EV battery state of charge?

Yes. In Advanced mode the integration estimates battery SOC, time to target, and expected finish time from charger data and the battery details you configure (initial SOC, battery capacity, correction factor).

Does the integration work with the new REVE firmware?

Yes. The integration recognizes REVE firmware by itself and reads and writes its settings, schedules, tariffs and charging limits through REVE's own interface. Readings REVE does not report stay unavailable. In manual mode (the charger app's “ignore schedule”, One Charge or Stop) the charger ignores schedules and limits until the connector is pulled out of the car. See the REVE section of the documentation.

Why does setup fail while the charger's web page works?

The integration is built for the latest firmware version of each line; an older version can answer its web page normally but reply to the integration's requests in a way setup can't use. Update the charger to the latest firmware of its line: message @energy_star on Telegram for the firmware files and instructions, then install the file through the charger's web interface. The setup dialog shows the concrete failure reason, and the troubleshooting guide explains what to report if the firmware can't be updated.
